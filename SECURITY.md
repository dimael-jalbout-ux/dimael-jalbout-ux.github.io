# Security and privacy

This repository is a static portfolio. It has no server, secrets, analytics, forms, cookies, or third-party runtime scripts. Calculator inputs and prototype search/filtering run locally in the browser and are not transmitted or stored.

Before making changes public, check that no client names, employer workpapers, private contact details, credentials, personal application records or non-fictional customer data have been added.

If you find a security or privacy issue in this repository, contact the owner through LinkedIn rather than including private details in a public issue.
